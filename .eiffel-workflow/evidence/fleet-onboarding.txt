================================================================================
1. BUILD COMMAND
================================================================================

    cd /d/prod/simple_rixgpt
    /d/prod/ec.sh release -config simple_rixgpt.ecf -target simple_rixgpt_app

ec.sh expands `release' into two finalizations:

    ec.exe -batch -config simple_rixgpt.ecf -target simple_rixgpt_app -finalize -c_compile
    ec.exe -batch -config simple_rixgpt.ecf -target simple_rixgpt_app -finalize -keep -c_compile

Run in the FOREGROUND, blocking. ec.sh refuses -c_compile passed directly and
refuses W_code modes, so `release' is the whole command.

The application was NOT run. RixGPT needs model.bin, a 21 MB weights payload
that is deliberately not in this repository, so a compile is the acceptance
here and is stated as such in the README.

Before the final build the target's EIFGENs subtree was removed, so this is a
clean compile and not an incremental one:

    rm -rf EIFGENs/simple_rixgpt_app

Note the naming: `release' ends by renaming the finalized binaries, so F_code
holds simple_rixgpt_lean.exe and simple_rixgpt_dbc.exe rather than a plain

5. TESTS
================================================================================

    rm -rf EIFGENs/simple_rixgpt_tests
    /d/prod/ec.sh test -config simple_rixgpt.ecf -target simple_rixgpt_tests
    ./EIFGENs/simple_rixgpt_tests/F_code/simple_rixgpt.exe

    Running simple_rixgpt tests...

      PASS: RIXGPT_MODEL compiles into the system
      PASS: RIXGPT_APP compiles into the system

      ========================
      Results: 2 passed, 0 failed
      ALL TESTS PASSED
      (compile proof only - generation needs model.bin, which is not in this repository)

    exit 0, zero warnings, log 72 lines.

This is a COMPILE PROOF and is labeled as one everywhere it appears - in the
class note, in the runner's own output, in the README and in the CHANGELOG.

Why it is not more than that: RIXGPT_MODEL has exactly one creation procedure,
`make (a_path: STRING)', and it takes the path of a RIXG weights file. Every
other feature of the class is either feature {NONE} or requires a loaded model.
The weights are a build payload from a private training pipeline and are not in
this repository, so there is nothing to exercise. A synthetic model.bin was
considered and rejected: a fabricated 4-dimension model would prove that the
header parser reads a file this same session wrote, and nothing about the real
weights.

What the target does prove is real: declaring a local of a class puts that class
in the system, so RIXGPT_MODEL and RIXGPT_APP are both fully type-checked and
finalized by this target. That is the check that breaks first when the engine is
edited.

The fleet's application exemplar, simple_reel, carries a hand-rolled TEST_APP
with a check_that/passed/failed runner rather than simple_testing + TEST_SET_BASE.
This runner follows that shape, so the two applications match.

7. FILE FORMAT VERIFIED, NOT ASSUMED
================================================================================

The README documents the RIXG header. Rather than describe it from the loader
alone, the header of the shipped bin/model.bin was read back and the two agree:

    magic                 RIXG
    format version        2
    dtype                 1  (fp16)
    n_layer               6
    n_head                6
    n_embd                384   (head_dim 64)
    vocab_size            316
    block_size            256
    vocab count           316

    file size             21,735,700 bytes
    header size           1,300 bytes  (4 + 4 + 4 + 5*4 + 4 + 316*4)
    weight bytes          21,734,400
    fp16 weights          10,867,200 exactly, no remainder

10,867,200 weights is the "about 10.9 M parameters" of the description, and the
clean division is independent confirmation that dtype 1 and vocab_size 316 were
read correctly.

================================================================================
8. LINE ENDINGS
================================================================================

Every pre-existing file in this project is CRLF: src/rixgpt_model.e (418 lines),
app/rixgpt_app.e (118), simple_rixgpt.ecf (30), simple_rixgpt.rc (6),
installer/RixGPT.iss (47). Sibling repos simple_json, simple_bnf and
simple_shaping are CRLF too and set core.autocrlf=true.

Every file written or edited in this pass was normalized to CRLF with a Python
bytes replace after the fact, and core.autocrlf=true is set on this repository
to match its siblings.

One trap worth recording: an inline Bash heredoc collapsed a doubled backslash,
so the first ECF patch wrote  location=".<TAB>esting\"  instead of
location=".\testing\". The repair was written to a script file that builds every
backslash with chr(92) rather than spelling one in source. Check ECF cluster
paths after any scripted edit.
